**[Открыть выполненный ноутбук](homework_1.ipynb)** · **[Исходные данные](experiment_data.csv)**

Сгенерировано 3572 пользователя одним запуском исходного алгоритма.
Seed: `4279692`. Подбор seed и повторная генерация ради значимых результатов не выполнялись.

| Проверка | Результат |
|---|---|
| SRM, план 50/50 | control 2067, test 1505; p = 5,29 × 10⁻²¹ |
| Баланс pre_activity | Mann–Whitney p = 0,000656; SMD = 0,149 |
| Ошибки страницы | control 1,306%, test 1,993%; Fisher p = 0,136 |

**Решение: остановить тест, исправить ошибки, перезапустить.**
Рост ошибок заложен в генераторе, но в данной реализации статистически не подтверждён.
Отсутствие значимости не доказывает безопасность.

В ноутбуке есть проверка качества данных, статистические тесты, доверительные интервалы,
поправка Holm, графики, аналитические выводы и бонус: точное сопоставление по активности.
После сопоставления осталось 2912 пользователей; причины SRM и ошибок не устранены,
поэтому исходный эксперимент валидным не становится.

## Файлы

- `homework_1.ipynb` — самостоятельный выполненный ноутбук с сохранёнными таблицами и графиками.
- `experiment_data.csv` — исходный уникальный набор данных; не заменять отфильтрованной выборкой.
- `generation_metadata.json` — seed, размер, SHA-256 и версии среды генерации.
- `generate_data.py` — исходный алгоритм с исправлением синтаксической опечатки; защита от перезаписи CSV.
- `analyze_experiment.py` — отдельный скрипт анализа и визуализаций.
- `requirements.txt` — зависимости для воспроизведения в Python 3.12.

## Запуск

```bash
python -m pip install -r requirements.txt
python analyze_experiment.py --data experiment_data.csv
```

Результаты скрипта появятся в `analysis_outputs/`. Для работы с ноутбуком откройте
`homework_1.ipynb` в Jupyter или VS Code из папки репозитория и выполните ячейки сверху вниз.
Для Colab загрузите в рабочую папку `experiment_data.csv` и `generation_metadata.json`;
при необходимости установите зависимости. Импортировать Python-скрипты для запуска ноутбука не нужно.

Данные уже сгенерированы. Для воспроизведения анализа повторно генерировать их не нужно.
Генератор намеренно завершится с ошибкой, если `experiment_data.csv` уже существует.

## Особенности исходного задания

Назначение 40/60 перезаписывается назначением, зависящим от активности; итоговое
соотношение следует проверять по CSV. Активность имеет дискретизированное
экспоненциальное распределение, хотя комментарий в условии называет его логнормальным.
Нулевой причинный эффект варианта не гарантирует равные маргинальные конверсии
при разном составе групп. Эти особенности разобраны в ноутбуке.

На образовательную платформу сдаётся ссылка на ноутбук. Сам ноутбук и CSV размещены
здесь, в репозитории; прикреплять их к ответу на образовательной платформе не требуется.
